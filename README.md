# PA-formula-in-selection-bias

> ⚠️ 本仓库代码位于 `reference_code/`，是 2020 年前后读博期间的历史实现，仅作参考与溯源，不代表当前可用状态；新的开发请另建目录（如 `src/`），不要直接改这里的文件。

## 这个项目研究什么

这个项目研究如何用 Pearson–Aitken 公式刻画 GWAS 中的入选偏倚，以及病例内选择如何改变 SNP 之间的相关。进一步目标是评估利用入选多基因评分进行校正的可能性。

## 方法/数据

拟结合多元正态分布、疾病阈值模型与 Pearson–Aitken 公式推导选择后的均值和协方差；尚未开展实际数据分析。
